# Amazon Fire TV Stick Lite (2020), model AFTSS (sheldon), Fire OS 7.7.1.7 (PS7717/5741), Android 9 / SDK 28
# Ads, telemetry, preloaded Amazon apps and Alexa extras. Packages are disabled for user 0, never uninstalled.
# Amazon's launcher (com.amazon.tv.launcher) stays enabled: Fire OS needs it, and the launcher's
# HomeRedirectService keeps it out of sight.
#
# Sections 1 to 5 come from https://github.com/eteen12/firetv-stick-aftss-cleanup (debloat.txt), whose
# sections 1 to 4 derive from Gathin23/cleanyourtv examples/amazon-fire-tv-stick-lite-2020/debloat.txt.
# Copyright (c) 2026 Gathin, MIT License.
#
# Apply:  TV_HOST=<ip> tools/disable.sh examples/amazon-fire-tv-stick-lite-AFTSS/debloat.txt
# Undo:   TV_HOST=<ip> tools/restore.sh examples/amazon-fire-tv-stick-lite-AFTSS/debloat.txt com.amazon.tv.launcher
#         TV_HOST=<ip> tools/venv/bin/python -I tools/tv.py 'settings delete secure enabled_accessibility_services'
#
# Kept on purpose (not in this list): com.amazon.tv.settings.*, com.amazon.venezia (Appstore), com.amazon.tv.ime
# (keyboard), remote/Bluetooth services, OTA updates, Alexa voice search (com.amazon.vizzini, aria, cardinal,
# ivona TTS, tcomm), Prime Video (com.amazon.firebat, com.amazon.tv.support), casting (cast.sink, dialservice,
# awvflingreceiver, whisperplay, whisperlink), profiles (com.amazon.prism.android.service), com.amazon.tv.oobe
# (needed for a factory reset), screensaver, accessibility (com.amazon.logan).
#
# Protected on this build. Fire OS refuses both `pm disable-user` and `pm suspend` for these, so they are
# listed only as comments. Block what they phone home to with DNS instead:
#   com.amazon.minerva.client.api, com.amazon.device.logmanager, com.amazon.device.crashmanager,
#   com.amazon.diode, com.fireos.usagestats.proxy, com.amazon.ftvads.deeplinking, com.amazon.tv.csapp,
#   com.amazon.tv.launcher
